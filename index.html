Job Title: Fresher DevOps Engineer (Male)

Location: Kochi

Job Summary

We are looking for an enthusiastic and motivated fresher DevOps Engineer (male) who is passionate about cloud technologies, automation, and infrastructure management. The ideal candidate should have a strong foundation in Linux, scripting, version control, CI/CD, containers, cloud computing, and DevOps tools. This role offers the chance to work on modern infrastructure, automation practices, and cloud‑based solutions while learning from experienced professionals.

Key Responsibilities

  1. Linux Administration
  2. Work with Linux OS (Ubuntu/CentOS/RHEL).
  3. Perform basic administration and troubleshooting.
  4. Manage users, permissions, and system services.
  5. Scripting & Automation
  6. Develop and maintain basic Shell/Bash scripts.
  7. Automate repetitive system administration tasks.
  8. Contribute to infrastructure automation initiatives.
  9. Version Control
  10. Use Git for source code management.
  11. Maintain repositories and follow best practices.
  12. Participate in code reviews.
  13. CI/CD Pipeline Management
  14. Understand and support CI/CD workflows.
  15. Assist in configuring and maintaining Jenkins pipelines.
  16. Help automate application deployment processes.
  17. Containerization
  18. Build and manage Docker images.
  19. Deploy and maintain Docker containers.
  20. Work with Docker Compose for multi‑container apps.
  21. Cloud Infrastructure
  22. Work with AWS (preferred) or other cloud platforms.
  23. Understand VMs, storage, networking, and IAM fundamentals.
  24. Assist in provisioning and managing cloud resources.
  25. Infrastructure as Code (IaC)
  26. Learn and implement IaC concepts.
  27. Work with Terraform for provisioning (preferred).
  28. Support automated infrastructure deployment.
  29. Kubernetes Administration
  30. Understand Kubernetes architecture and core components.
  31. Work with Pods, Deployments, Services, and Namespaces.
  32. Use kubectl commands to manage resources.
  33. Networking Fundamentals
  34. Understand TCP/IP, HTTP/HTTPS, DNS, SSH, and load balancers.
  35. Assist in diagnosing basic network connectivity issues.
  36. Monitoring & Logging
    • Gain exposure to Prometheus and Grafana.
    • Monitor application and infrastructure performance.
    • Understand logging and monitoring best practices.
  37. Database Fundamentals
    • Basic understanding of MySQL or PostgreSQL.
    • Execute simple SQL queries and grasp relational concepts.
    • Support database‑related deployment activities.

Qualifications & Skills

  • Bachelor’s degree in Computer Science, IT, or related field.
  • Fresh graduates or candidates with internship experience in DevOps are encouraged.
  • Good understanding of Linux and Shell scripting.
  • Basic knowledge of Git, Docker, Jenkins, Kubernetes, and Terraform.
  • Familiarity with AWS cloud fundamentals (preferred).
  • Basic networking concepts and SQL knowledge.
  • Strong analytical, troubleshooting, and problem‑solving skills.
  • Good communication and teamwork abilities.
  • Self‑motivated with a strong willingness to learn new technologies.

Preferred Candidate

  • Passionate about Cloud Computing and DevOps.
  • Eager to learn automation, CI/CD, IaC, and container orchestration.
  • Quick learner, adaptable, positive attitude, excellent collaboration and communication skills.
